# Demo-only self-hosted display fonts

Retrieved 2026-10-01 from the Google Fonts repository:

- Barlow Condensed Bold: https://github.com/google/fonts/tree/main/ofl/barlowcondensed
- Cinzel variable: https://github.com/google/fonts/tree/main/ofl/cinzel
- Space Grotesk variable: https://github.com/google/fonts/tree/main/ofl/spacegrotesk

Each family contains its upstream OFL.txt. Body text uses system fonts. Files belong to local preview fixtures and are copied only by the showcase exporter. Production template pages do not load these fonts.
